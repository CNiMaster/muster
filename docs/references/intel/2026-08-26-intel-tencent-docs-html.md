## 拆解要点（依据截图）

- 主题：腾讯文档把 HTML 当文档资产的能力边界（创作/编辑/AI/协同）。
- 核心结论：HTML 已「文档化」，但未真正「协同化」——多人编辑、评论、AI 编辑各有缺口。
- 缺口清单（截图归纳）：多人实时编辑冲突、评论区、AI 编辑留痕/回滚、DOM 快照、移动端只读降级。

## 收编：拆解方法论模板（后续竞品拆解套用）

1. 现状盘点：能力矩阵（维度 × 支持度）。
2. 流程走查：关键用户旅程逐步验证。
3. 缺口清单：明写「能 / 不能 / 降级」。
4. 下一步判断：哪些缺口是产品机会、哪些是能力边界。
