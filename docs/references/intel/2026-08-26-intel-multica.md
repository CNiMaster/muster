# 情报卡：Multica——云端多 AI Agent 协作平台拆解

- 日期：2026-08-26
- 来源：拆解长图（本地 `~/Downloads/IMG_3322.PNG`，1599×15785）
- 一句话取用点：同赛道唯一直接对标；结论=muster 强在组织与治理层，可从它拿任务视图细节与多厂商叙事。

## 拆解要点（依据截图）

- 定位：把云上多 AI Agent（不同厂商）的协作放进一个项目里跑起来。
- 核心主张：一个项目=多 agent 协作单元；任务在 agent 间流转，用户看板式跟进。
- 拆解者归纳的三个产品杠杆：多 agent 编排、任务/项目管理、协作可见性。

## 对标表（Multica vs muster）

| 维度 | Multica（依据拆解） | muster 现状 | 结论 |
|---|---|---|---|
| 任务编排 | 项目内任务流转 | Task 10 态+任务树+蜂群 spawn_tasks+循环任务 | muster 强（业务级状态机 vs 看板流转） |
| 多 Agent 协作 | 云端多厂商 agent 拉进同项目 | 执行器统一池（CLI/API 混排）+固定岗+专家团+借调 | 打平；muster 多一层组织模型 |
| 进度可见性 | 看板/列表视图 | 任务树+WorkTraceBlock+执行 trace+上下文徽章 | 打平，muster 粒度更细 |
| 审批与治理 | 拆解未见深治理 | 审批档+权限中心+验收庭+staging 集成区+token 治理 | muster 明显强——护城河在此 |
| 模型/供应商中立 | 主打多厂商云 agent | 执行器档案+能力标签+健康降级链 | 打平 |
