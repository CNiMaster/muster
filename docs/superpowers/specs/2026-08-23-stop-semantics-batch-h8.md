# 批次 H8：停止语义 + 即时回执 + 环境预检

状态：proposed（2026-08-22 与用户多轮定稿，含评审轮 I5 双跑语义收敛）
来源：批次 H 评审 I5（插话双跑）+ 用户三轮设计收敛（单停止/安全规则/按钮菜单/打断记录/批量暂停）+ 用户新增两条观察（即时回执感、环境预检入程序）。

## 用户定稿设计

### 1. 停止=单动作，内部按执行状态自动分级（安全规则）

| 当前在干什么 | 停止动作 |
|---|---|
| 正在写/编辑文件 | 等这次写完（整文件原子写，到边界即停） |
| 正在跑 Bash 命令 | 等命令结束再停（中断 git/npm 可恢复但烦人；worktree 隔离兜底） |
| 正在等模型响应 | 直接停 |

- **超时兜底**（默认 60s，设置可调）：等待边界有上限，防 watch/长命令把停止挂死；到点自动强停（SIGTERM），半成品走保留分支+文件清单，**同样落打断记录**。
- 实现要点：请求停止标志（task 行 stop_requested）→ 引擎在工具调用边界检查（API tool-loop 每轮工具后天然可查；CLI 在 onToolCall/onOutput 回调边界查+SIGINT 优雅打断让模型收尾总结=停点摘要）。
- **I5 收敛**：停止后 state='paused'（不是回 queued 让位重跑）——打断不是重跑；插话模式同语义改造。
- pauseTask 既有缺陷顺带修复：现在只改状态不通知引擎（运行中"暂停"实际停不下来），统一并入本套安全停逻辑。

### 2. 按钮三态合一（评审 spec 偏差③消解）+ 侧边菜单

```
[输入框空 + 任务运行中]  [ ■ 停止 ⌄ ]   ← 单击=停当前任务；⌄ 菜单=「暂停本项目全部任务（N 个运行中）」
[输入框有字]             [ 发送 ↑ ]     ← 发送后进排队通道，按钮回停止态
[任务空闲]               [ 发送 ↑ ]
[已点击停止，等边界]      [ ⏸ 停止中… ]  ← 禁用态防连击；内部超时自动兜底，无需二次操作
```

- 批量暂停第二入口：工作现场面板执行者目录顶部「全部暂停」；逐任务走同一安全停。
- 不经负责人 agent 转发暂停（控制面确定性操作直做）；全部停下后**可选**自动派汇总任务给第一负责人（"各任务停点清单，请建议下一步"——分析活才给 agent）。

### 3. 打断记录卡（停后出现在消息流/任务详情）

- 停点：停在第几步、最后动作、模型收尾总结一句
- 已改文件清单（含未完成标注）
- 三出口：**继续**（从保留 worktree 现状续跑，不从头来）｜**补齐**（发新任务给同一员工，自动附打断记录）｜**回退**（丢弃这批改动重来）
- 工程要点：停止时 worktree 保留（现有 unpublished_changes_kept 机制升级为面向用户的记录卡）；"继续"要求引擎复用 task_runtime 而非重建（现状会从基线重来——需改）。

### 4. 即时回执（用户新增观察：操作后必须立刻"被回应"）

- 用户点 停止/暂停/↑立即 的**那一刻**，对话区立刻出系统回执消息：
  - 受理：「已请求停止——等待当前命令（Bash: npm test）完成后停下」（带当前动作名）
  - 生效：「已停止：完成 2/5 项，改了 2 个文件」+ 打断记录卡
- 生效的可验证性（用户"后台停没停我不清楚"的解法）：任务状态徽章可见变「已暂停」+ LiveProcessBar 消失 + trace 停止滚动——三条线索交叉确认。
- 排队条 flush 同理：立即回执「已打断并送出」。

### 5. 环境预检（用户新增：经验入程序）

- **产品侧**：执行器 spawn 失败的错误分类识别安全拦截特征（EPERM/Gatekeeper 报错串），对话区给可操作提示（去 隐私与安全性 允许 / 对二进制去隔离属性），不裸报错。
- **工程侧**：`npm run preflight`——测试/冒烟前探测 node/git/esbuild spawn 正常 + 检测隔离属性（xattr -l），发现即提示"请先完成系统授权再跑测试"，把安全弹窗从测试中途随机炸变为开跑前一次性处理。playwright webServer 命令前置调用。

## 实施边界

- 迁移：task 表加 stop_requested 列（官方时间戳命名）。
- CLI/API 执行器分别落地边界检查；SIGINT 优雅路径 + SIGTERM 强停路径。
- H5 的 interruptTask 保留为"强停"原语；新 requestStopTask 为"安全停"入口；插话模式改为安全停+paused 语义。
- 测试：安全停边界（写文件中/Bash 中/模型等待中三态各一例）、超时升级、打断记录三出口、按钮三态、批量暂停、预检脚本。
- 不做：历史树回退、蜂群批量暂停的依赖序（并行停即可）。
